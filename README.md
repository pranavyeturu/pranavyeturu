## 🧠 Featured Projects

### 🔍 ReQon — Autonomous AI Web Quality Platform

[![Repo](https://img.shields.io/badge/GitHub-ReQon-181717?style=for-the-badge&logo=github)](https://github.com/pranavyeturu/Requon)

AI-powered web testing platform that autonomously crawls applications, detects defects, runs performance tests, tracks regressions, and generates an explainable application Hygiene Score.

**Highlights**
- LangGraph-based AI orchestration
- Playwright + Crawl4AI autonomous crawling
- XGBoost + LLM page classification
- Load, stress, and soak testing
- Neo4j knowledge graph for historical defect tracking
- Redis-backed state management
- FastAPI backend and Docker deployment
